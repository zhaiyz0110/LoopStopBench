# Superseded Development Report

The original `m2_report.md` was an internal milestone report written before
the out-of-fold baseline correction and the P0 exclusion of `Mbpp_793`. Its
sample counts, confidence intervals, and several interpretations are not valid
for the released manuscript.

The public repository replaces that report with this notice so that its
historical values are not mistaken for final results. Use:

- [`AUTHORITATIVE_RESULTS.md`](AUTHORITATIVE_RESULTS.md) for final numerical
  values and reporting notes; and
- [`RESULT_MANIFEST.md`](RESULT_MANIFEST.md) for the mapping from paper
  analyses to machine-readable CSV files.

The frozen CSV artifacts remain available. Final code analyses use files
prefixed with `p0_excl_` and exclude `Mbpp_793`.
